# PySide Iconify for VS Code

Документация, автодополнение, проверки и поиск иконок для `pyside-iconify` прямо в редакторе.

## Зачем

[pyside-iconify](https://github.com/LingChen-tsjmdlc/pyside-iconify) даёт `QIcon` источник данных: `IconWidget("mdi:home", color="red")`. Ошибки при этом обнаруживаются поздно:

- имя иконки — просто текст, по нему не видно, какая это иконка
- несуществующий параметр или параметр другой функции ломается только при выполнении строки
- допустимые значения `size`, `color`, `opacity` и `animation` легко забыть

Это расширение переносит ответы в редактор.

## Возможности

| Возможность   | Что вы получаете                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Иконки в коде | Настоящая иконка рисуется на месте её имени, а при наведении показывается крупнее                                                    |
| Документация  | Наведите курсор на вызов или на его параметр, чтобы увидеть назначение, допустимые значения и значение по умолчанию                  |
| Параметры     | Автодополнение имён параметров и значений `animation`, `spin` и подобных                                                             |
| Проверки      | Неизвестные или конфликтующие параметры и недопустимые значения подчёркиваются; при похожем написании есть быстрое исправление       |
| Имена иконок  | Введите два или больше символов внутри строки `icon` и выберите из результатов поиска Iconify в реальном времени, каждый с картинкой |
| Поиск иконок  | Нажмите `Ctrl+Alt+Shift+I` (`Cmd+Alt+Shift+I` в macOS), чтобы найти иконки и вставить одну в позицию курсора                         |

Всё работает для `IconWidget`, `get_icon`, `get_pixmap` и `set_icon`, импортированных из `pyside_iconify`. Проверки сообщают только о том, в чём уверены. То, чего они знать не могут, например значение из переменной, они не трогают.

## Иконки в строке

Настоящая иконка рисуется прямо в коде, на месте имени иконки. Обрабатывается только аргумент `icon`, и только обычные однострочные строки вроде `"mdi:home"`. Строка с курсором всегда показывает текст, чтобы его можно было править. Кавычки остаются всегда. При наведении на имя в любом режиме показывается иконка крупнее.

Стиль выбирается настройкой `pyside-iconify.inlineIcons`:

| Значение                  | Результат                                              |
| ------------------------- | ------------------------------------------------------ |
| `off`                     | Только текст. Иконка не рисуется.                      |
| `iconBefore`              | Иконка, затем текст.                                   |
| `iconAfter`               | Текст, затем иконка.                                   |
| `iconOnly` (по умолчанию) | Только иконка. Имя иконки скрыто.                      |
| `gutter`                  | Иконка на полях, перед номером строки. Текст остаётся. |

```json
"pyside-iconify.inlineIcons": "iconOnly"
```

## Горячие клавиши

| Клавиши                                        | Что делают                                                                                                                        |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `Ctrl+Alt+Shift+I` (`Cmd+Alt+Shift+I` в macOS) | Открывают поиск иконок в файле Python. Выбранное имя вставляется в позицию курсора.                                               |
| `Alt+Enter`                                    | Показывает подсказки в позиции курсора в файле Python. Внутри строки `icon` это имена иконок.                                     |
| `Ctrl+Space`                                   | Собственная клавиша VS Code: открывает или закрывает панель сведений рядом со списком подсказок. Крупная иконка показывается там. |

## Iconify IntelliSense

Рекомендуем [Iconify IntelliSense](https://marketplace.visualstudio.com/items?itemName=antfu.iconify). Оно отвечает за Iconify в веб-языках, а это расширение — за `pyside-iconify` в Python.

По умолчанию они не пересекаются: Iconify IntelliSense работает только в языках из своей настройки `iconify.languageIds`, а `python` в ней нет. Если вы добавили туда `python`, подсказки иконок и иконки в строке будут дублироваться — удалите его из этого списка. Если в файлах `.py` всё равно видны две карточки при наведении, добавьте `**/*.py` в его настройку `iconify.preview.exclude`.

## Требования и использование сети

- VS Code 1.73 или новее
- Файлы Python, импортирующие из `pyside_iconify`
- Доступ к публичному API Iconify (`https://api.iconify.design`) для поиска иконок и их картинок

Отправляются только искомые слова и имена иконок. Ваш код не загружается, а Python разбирается на вашем компьютере.

Ответы кэшируются в папке хранилища расширения, поэтому повторные действия быстрее, а к API обращений меньше. Результаты поиска хранятся 14 дней, списки наборов иконок — 30 дней. Картинки иконок остаются, пока вы не удалите папку. Без сети документация, автодополнение параметров и проверки работают по-прежнему, а уже сохранённые иконки продолжают показываться.

## Известные ограничения

- Существование иконки не проверяется, проверяется только форма `prefix:name`. Неизвестное имя просто остаётся без картинки.
- Проверки читают только литеральные значения. Значение из переменной никогда не оценивается.
- `iconOnly` скрывает текст приёмом CSS, который VS Code не документирует; тот же приём использует Iconify IntelliSense. Если будущая версия VS Code его проигнорирует, будут видны и текст, и иконка.
- Картинки в окне поиска требуют VS Code 1.81 или новее. В более старых версиях показываются только имена.
